# Privacy Policy

**Extension:** Open Links in Discord App
**Last updated:** 2026-08-24

## Summary

This extension does **not** collect, store, transmit, or sell any data.

## Details

- The extension runs a content script only on Discord's web hosts
  (`discord.com` and its `www.`, `canary.`, and `ptb.` subdomains).
- On those pages it reads only the current page's **URL path** in order to
  redirect it to the equivalent Discord desktop-app deep link
  (`discord://…`).
- It makes **no network requests**, uses **no background processes or
  servers**, sets **no cookies**, and uses **no analytics or tracking**.
- No personal information, browsing history, credentials, or any other data is
  collected or shared with the developer or any third party.

## Permissions

The extension requests host access to Discord's web domains solely to perform
the redirect described above. It requests no other permissions.
